# Project workflow

- Build and refine this website locally.
- Do not use ChatGPT Sites for this project.
- Do not deploy, publish, or push to a hosting service unless the user explicitly requests deployment.
- Keep local development commands free of deployment steps.
- Prioritize the mobile layout, complete real product photographs, smooth touch interactions, and accessible motion.

The editable website is in `dist/index.html`, `dist/style.css`, and `dist/app.js`. Its assets are local in `dist/assets/`.

Start the local preview with `npm run dev` or `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`.
